Red5 Logback Syslog manual

This manual describes Red5 Logback Syslog, a single jar that adds a Logback appender for syslog to Red5. The appender is built on a modernized copy of the syslog4j client and server, repackaged under org.red5, so it carries the syslog4j feature set without an extra dependency.

Applications log through SLF4J as usual; this project only changes where Logback sends the events.

Contents

  1. Introduction — What the project is, how it relates to Logback's SyslogAppender and the papertrail appender, requirements and license.
  2. Getting started — Adding the jar, a first logback.xml, and checking that messages arrive.

  6. Reliability — The asynchronous queue, overflow policies, the backlog, reconnect backoff, shutdown and the status messages you will see.

  8. Troubleshooting and limitations — Common problems, how to read Logback's status output, and the known limitations.
Where to start

If you already use Logback's own SyslogAppender, read the migration notes. Otherwise begin with Chapter 2.
